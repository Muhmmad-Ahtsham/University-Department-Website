Academic Programs

BS Computer Science

Four-year undergraduate program covering programming, databases, networks and software development.

BS Software Engineering

Four-year program focused on requirements, design, testing, project management and web engineering.

BS Information Technology

Four-year program in systems administration, web technologies, databases and IT management.

BS Data Science

Four-year program in statistics, machine learning, data engineering and visualization.

MS Computer Science

Two-year research-oriented program with thesis or course-work options.
